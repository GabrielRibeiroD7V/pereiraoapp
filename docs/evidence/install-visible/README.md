# Orientação inline na Home

Capturas locais de build Preview: [393×852](instalacao-home-mobile.jpg) e [1280×900](instalacao-home-desktop.jpg). Chromium emulado; não Safari/iPhone físico. O acesso aparece sem aguardar o convite, não abre modal automaticamente e pode abrir instruções no toque. Detecção real deste browser usa orientação genérica, sem simular prompt do Safari. Instruções iOS e orientação para outro navegador são verificadas em testes com plataforma simulada, não no aparelho.

Testes novos: Home dispensada mantém orientação; Conta autenticada após carregar a sessão mantém orientação; seletor de serviços recebe seis opções e pode escolher Construção/Elétrica sem gravar. Nenhum dado operacional foi alterado.
